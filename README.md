# Quests_In_Game_WebAPI 🎮🛜
To repozytorium zawiera prostą implementację Web API napisanego w ASP.NET Core w wersji 10.0, które ma tworzyć rzeczy związane z grą i questami w niej (np. do jakiegoś sieciowego RPG).

* Aktualizacja (4.06.2026): Dodanie podstawowych funkcjonalności CRUD wszystkich klas (Character, Guild, Quest, QuestCompletion)
