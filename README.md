# Quests_In_Game_WebAPI 🎮🛜
To repozytorium zawiera prostą implementację Web API (imitującego "Mini silnik do gier") napisanego w ASP.NET Core w wersji 10.0, które ma tworzyć rzeczy związane z grą i questami w niej (np. do jakiegoś sieciowego RPG). </br>
Poza samym API, do przechowywania danych użyto dokumentowej bazy danych z wykorzystaniem RavenDB.
